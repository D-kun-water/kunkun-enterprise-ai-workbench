# 本地版本发布检查

日期：2026-09-20。范围：当前工作树、代码、接口、运行隔离、数据、产品文档及交付边界。

结论：本地回归通过，真实模型仍有 2/9 有答案题需要安全降级。维护者已确认三份制度为参考公开企业资料融合整理的验证语料，不列具体企业出处。公开发布目录已移除旧 Git 历史、本地环境配置、私有合同、运行索引、输出和临时目录；当前仍不是生产就绪结论。

## 已修复并回归

| 问题 | 改动与证据 |
|---|---|
| 并发反馈读改写丢记录；损坏 JSON 被误当空文件 | 单进程按路径共享锁、临时文件原子替换；并发、损坏与失败恢复测试 |
| 离线测试读写运行数据，依赖模型措辞与机器权限配置 | 独立临时目录与确定性回归；真实模型审计单独执行；不清理其他运行的临时目录 |
| 合同空白主体、条款编号、一般担保被误作完整字段 | 核验具名主体、数值与对应条款；覆盖含税/不含税、履约保函和长段落 |
| 正文“甲方”压过合同首页主体名称 | 优先保留双方具名身份行，避免普通提及抢占证据 |
| 合同范围配置损坏、未解析合同仍进入审阅 | 权限损坏时关闭合同访问；解析失败不输出成功核对；制度问答可继续 |
| 合同查询关联到无关制度、UI 入口与允许范围不一致 | 关联制度增加门控；所有预置角色可进入，但列表按允许范围过滤 |
| 编辑备注后结果消失、特殊 ID 请求失败、身份切换遗留、同内容合同串用备注 | 结果按角色/合同/文本哈希/查询隔离；控件加入合同 ID；编码 ID；切换时清除状态；AppTest 回归 |
| 向量查询失败导致全部检索不可用；索引缺元数据被加载 | BM25 降级并标记；校验元数据、维度和非有限向量数值 |
| 目录被当正文、相似动作外推、起草与准入混淆 | 排除纯目录；对象与流程约束；高风险改写问题回归 |
| 模型增删“原则上”、入职时长被误作日历年资格 | 显式标记原文要点降级；请求缺失日期，不推断资格 |
| 兼容模型返回空内容或 null 被当答案 | 空响应按失败处理；模型调用超时收敛；不伪装正常生成 |
| 中文目录导致 Compose 项目名无效、容器连接宿主机地址混用 | 固定项目名，独立模型地址，端口仅映射本机 |

合同增加变更签证、质保、验收、违约四类，共 12 类；增加原文位置、文本哈希、会话内人工状态和导出。它仍是规则核对，不是完整风险识别或合同审批。
