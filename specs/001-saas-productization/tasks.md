> 编号说明：下文“阶段零、阶段一……”是执行任务分组；产品版本划分以 PRD 和 SaaS 路线图中的“第一至第四阶段”为准，两套编号不能混用。

## 1. 使用规则

- `[x]` 表示已有本轮可复现证据；`[ ]` 表示尚未完成。
- `[并行]` 表示与同阶段其他标记任务可并行。
- 安全接入任务是敏感或多人试点的前置条件，不受下文分组先后限制。
- 任务完成必须同时有产物、验证结果和事实边界，只有页面或占位代码不算完成。

## 3. 阶段一：单租户试点（条件触发）

**启动条件**：获得已授权资料及明确业务负责人。敏感资料、多人或远程访问前，必须先完成 T022–T025、T027 中的安全接入与验收。

- [ ] **T012** 与试点负责人确认用户、场景、资料范围、数据处理边界和退出条件。
- [ ] **T013** [并行] 建立资料来源、授权、脱敏、保留和删除清单。
- [ ] **T014** [并行] 从真实问题中建立 20–50 条验收案例，包含必答事实、禁止事实、来源和拒答。
- [ ] **T015** 只导入通过检查的资料，在独立环境完成解析、检索和来源核验。
- [ ] **T016** 定义问题解决率、人工转接率、知识更新时长和有效反馈的分母及排除项。
- [ ] **T017** 建立坏例归因：资料缺失、解析失败、检索错误、答案组织错误、越权或超范围。
- [ ] **T018** 完成至少一个观察周期，输出技术指标、业务指标和运营成本分栏报告。
- [ ] **T019** 记录继续试用、扩围、停止或转向的决策及证据，不预设必须 SaaS 化。
- [ ] **T020 阶段门槛**：至少一个试点闭环完成，并形成按影响排序的真实阻塞清单。

## 4. 阶段二：企业交付能力（按阻塞项选择）

**启动条件**：T022–T025 和安全恢复先于敏感/多人试点；其他扩展由实际资料更新和接入问题触发，不必全部建设。

- [ ] **T021** 实现不可变文档版本、候选索引、发布指针和回滚验证。
- [ ] **T022** 接入一个真实企业身份源，服务端生成用户和组织上下文。
- [ ] **T023** 在检索前完成角色、部门、知识库和资源授权过滤。
- [ ] **T024** 验证未授权与不存在资源不会泄露标题、金额、片段、来源或存在性。
- [ ] **T025** 为身份、权限变更、文档发布、合同访问和管理操作建立审计记录。
- [ ] **T026** 仅实现试点最需要的一个文档连接器，并覆盖幂等、重试、权限映射和失败回退。
- [ ] **T027** [并行] 完成备份恢复、故障处理和敏感日志检查。
- [ ] **T028 阶段门槛**：真实阻塞项关闭；越权测试无泄露；文档更新失败可恢复到上一可用版本。

## 5. 阶段三：共享 SaaS（延后评估）

**启动条件**：至少两次独立交付证明需求与流程具有共性，且共享部署有明确成本、交付或运维收益。

- [ ] **T029** 固化服务端租户上下文，禁止信任客户端传入的租户和角色。
- [ ] **T030** 为数据、对象、索引、缓存、任务、反馈、合同、审计和导出建立租户隔离。
- [ ] **T031** 使用两个同名但内容不同的测试租户执行全链路隔离矩阵。
- [ ] **T032** 提供版本化接口、稳定错误码、请求标识、幂等和租户级限流。
- [ ] **T033** 记录可去重、可聚合、可对账的用量事件；不包含问题正文或敏感文档内容。
- [ ] **T034** 验证独立部署到共享服务的迁移、校验和回滚路径。
- [ ] **T035 阶段门槛**：双租户交叉泄露为 0，迁移可回滚，共享收益有证据；否则继续独立部署。

## 6. 暂不进入任务清单

- 自动收费、支付、发票和复杂套餐；
- 生产级服务承诺和灾备指标；
- 多智能体自主编排；
- 大量猜测性连接器；
- 用 PostgreSQL、对象存储、消息队列或微服务重写全部现有实现；
- 将 AI 前沿资讯接入统一智能体，除非真实用户需求证明其优先级。
